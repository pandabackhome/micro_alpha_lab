# 较长正股结构：成交VWAP、十五分钟趋势、区间回测

2026-09-18，前面多轮一分钟形态搜索之后固定。本轮5个正股规则×180/300秒持有期=10组合，不搜索超参数。旧前5个评估日筛选，旧后4日及已查看的新增2日分别报告。

VWAP按当日9:30以后、当时已可用的QQQ录制成交价×成交量累计计算，排除无效价格和数量；沿用源数据不去重政策。它是录制数据按可用时间计算的VWAP，并非交易所完整成交的官方VWAP。只使用已接收成交，不把晚到成交向过去回填。

过去900秒收益作为较长趋势，要求其两个端点新鲜、过去901秒至少95%正股报价有效，且原过去300秒全部有效。VWAP、15分钟收益和300秒区间均因果计算。60秒区间、5秒成交量、5/60秒收益复用已有特征。15分钟收益绝对值、VWAP相对偏离绝对值及5秒成交量的75%分位，均只用此前5日同半小时、每30秒采样，至少100个有效观测。

逐秒检查，在某条规则由不满足变成满足、或方向直接翻转时才产生事件。当前及前一秒的历史阈值和有效性都必须就绪，不固定某个分钟秒数。

1. `vwap_reclaim`：价格向上穿过VWAP且15分钟收益为正，买CALL；向下且15分钟收益为负，买PUT。
2. `trend_pullback`：15分钟趋势超过历史强度门槛，最近60秒逆向、最近5秒重新顺向，价格仍在VWAP的趋势一侧，顺大趋势。
3. `vwap_stretch_fade`：偏离VWAP超过历史门槛、最近5秒开始向VWAP回归，反向偏离交易。
4. `channel_breakout`：突破之前300秒最高/最低价，15分钟强趋势同向且5秒成交量超过历史门槛，顺突破方向。
5. `opening_retest`：先越过开盘15分钟区间，至少60秒后再次从区间内越过同一边界，且15分钟方向一致，顺重新突破方向。首次越界本身不作为回测入场。

统一买入当时平值期权，信号后1秒、报价年龄≤1秒且晚于信号，单仓位、同合约退出，每边0.65美元及1bp，缺退出最多等30秒、未平仓保留压力损失。候选筛选门槛不变，最多3个；历史样本和已重复使用的新增日期不再声称独立验证。
